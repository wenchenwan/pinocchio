## 1. 雅可比是什么

关节 $i$ 的雅可比 $J_i$（$6\times n_v$）把广义速度映射到该关节坐标系的**空间速度（twist）**：

$$
\boxed{\,v_i=J_i(q)\,\dot q\,}
$$

- 上 3 行是线速度、下 3 行是角速度（Pinocchio 约定 `[linear; angular]`）。
- IK、操作空间控制、接触约束、力/力矩映射（$\tau=J^\top f$）都靠它，见 [逆运动学IK解析.md](逆运动学IK解析.md)。
- "整机雅可比" `data.J`（$6\times n_v$）是所有关节**运动子空间列**在世界系的堆叠，是抽取任意关节/frame 雅可比的公共底料。

## 2. `computeJointJacobians`：整机雅可比 `data.J`

一趟前向递推（`JointJacobiansForwardStep`），和运动学 §3 几乎一样，只多一行填 `data.J`：

```cpp
jmodel.calc(jdata, q);
data.liMi[i] = model.jointPlacements[i] * jdata.M();
data.oMi[i]  = (parent>0) ? data.oMi[parent]*data.liMi[i] : data.liMi[i];

jmodel.jointExtendedModelCols(data.J) = data.oMi[i].act(jdata.S());   // ★ 世界系运动子空间
```

**核心公式**：`data.J` 里属于关节 $i$ 的那几列 =

$$
\boxed{\,{}^oJ_i={}^oM_i\cdot S_i={}^oX_i\,S_i\,}
$$

即把关节 $i$ 的**局部运动子空间** $S_i$（`jdata.S()`）通过伴随 ${}^oX_i$ 变换到**世界系**。物理含义：关节 $i$ 单位速度在世界系里造成的 6D 空间速度。

- 只需 $q$（雅可比只依赖位形）。
- 有个重载 `computeJointJacobians(model, data)`（不带 $q$）：假设 `oMi` 已由别的算法（如 ABA/CRBA）算好，只跑填 `data.J` 那一步（`JointJacobiansForwardStep2`），省去 `calc` 和 FK。

## 3. 为什么 `data.J` 一次算全、且天然稀疏

关节 $i$ 的速度是**它支撑链上所有祖先关节**贡献的叠加（见 [正向运动学 §5 速度递推](正向运动学解析.md)）：

$$
v_i=\sum_{j\in\text{support}(i)} {}^oX_j\,S_j\,\dot q_j
=\sum_{j\in\text{support}(i)} {}^oJ_j\,\dot q_j
$$

所以：

- **一次算全**：`data.J` 把每个关节的 ${}^oJ_j={}^oX_jS_j$ 都存好，任意关节 $i$ 的雅可比就是"取出 $i$ 的祖先列"，无需重算。
- **天然稀疏**：关节 $i$ 的雅可比里，**只有 $i$ 的祖先（支撑链）列非零**，其余为 0。这就是 [雅可比稀疏模式解析.md](雅可比稀疏模式解析.md) 讲的支撑链稀疏。`getJointJacobian` 正是沿 `parents_fromRow` 链只遍历这些非零列。

> 因为存的是世界系子空间，`data.J` 也被 [CoM 雅可比](质心与质心动量解析.md)、[CRBA/ccrba](质量矩阵CRBA解析.md) 直接复用——它们都从同一个 `data.J` 取列。

## 4. `getJointJacobian`：抽取某关节雅可比 + 参考系变换

`getJointJacobian(model, data, joint_id, rf, J)` 从 `data.J` 抽取关节 `joint_id` 的 $6\times n_v$ 雅可比，并变换到参考系 `rf`。核心逻辑（`details::translateJointJacobian`）：

```cpp
// 沿 joint_id 的支撑链，只遍历非零列（用 parents_fromRow 跳链）
for (jExtended = colRef; jExtended >= 0; jExtended = parents_fromRow[jExtended]) {
  MotionIn  v_in (Jin.col(jExtended));    // data.J 里的世界系列
  MotionOut v_out(Jout.col(...));         // 输出列
  // 按 rf 做变换（见 §5）
}
```

- **只遍历支撑链**：`jExtended = parents_fromRow[jExtended]` 沿 DoF 级父链上跳，天然跳过零列，$O(\text{depth})$ 而非 $O(n)$。
- **mimic 关节**：额外一趟把"被驱动关节"的贡献累加到"主动关节"列（`mimic_parents_fromRow` 链），普通模型不触发。见 [multibody §2 mimic](multibody子系统解析.md)。

## 5. 三种参考系的变换公式

`data.J` 存的列是**世界系、作用点在世界原点**的 6D 空间速度。三种参考系是"把这个 twist 表达到哪里"：

| `rf` | 变换代码 | 公式 | 含义 |
|---|---|---|---|
| **WORLD** | `v_out = v_in` | ${}^oJ_i$ 直接用 | 世界系、原点在世界原点的空间速度 |
| **LOCAL** | `v_out = placement.actInv(v_in)` | ${}^iX_o\,{}^oJ_i=S_i$ | 变换回关节 $i$ 自身体坐标系 |
| **LOCAL_WORLD_ALIGNED** | `v_out = v_in; v_out.linear -= t × v_in.angular` | 只平移作用点到关节 $i$ | 世界朝向、作用点在关节 $i$ |

### 5.1 WORLD

`data.J` 本就是世界系表达，直接拷贝。得到的 $v=J\dot q$ 是"关节坐标系原点那个点、在世界系下、绕世界原点"的空间速度。

### 5.2 LOCAL

`placement.actInv(v_in)`：用 ${}^oM_i$ 的逆伴随把 twist 从世界系搬回关节 $i$ 体系。因 ${}^oJ_i={}^oX_iS_i$，逆变换恰好还原成 $S_i$——即关节自身体系下的雅可比。IK 里 `computeJointJacobian` 默认给 LOCAL（右扰动雅可比），见 [IK 解析 §3.3](逆运动学IK解析.md)。

### 5.3 LOCAL_WORLD_ALIGNED

只做**作用点平移**、不转朝向：

$$
v_{\text{out}}^{\text{lin}}=v_{\text{in}}^{\text{lin}}-t\times v_{\text{in}}^{\text{ang}},\qquad
v_{\text{out}}^{\text{ang}}=v_{\text{in}}^{\text{ang}}
$$

其中 $t={}^oM_i$ 的平移（关节在世界的位置）。这是空间速度的**平移变换**：把作用点从世界原点移到关节 $i$，角速度不变，线速度扣掉 $t\times\omega$ 的杆臂耦合。结果是"末端点、世界朝向"的速度——机器人学里最常说的"末端速度"就是这个，也是 IK/操作空间控制的常用系。见 [正向运动学 §9](正向运动学解析.md)。

> 三者角速度部分相同（LOCAL 除外，它连朝向也转）；区别只在线速度的作用点/朝向。

## 6. `computeJointJacobiansTimeVariation`：$\dot J$

$\dot J$ 满足 $a_i=J_i\ddot q+\dot J_i\dot q$（加速度里那个非 $\ddot q$ 项）。它同时依赖 $q,\dot q$。递推在算 `data.J` 的同时，用速度把每列对时间求导：世界系子空间列的时间导数 $\frac{d}{dt}({}^oX_jS_j)={}^oX_j(v_j\times S_j)$（子空间被关节速度"旋着走"），存进 `data.dJ`。

用途：

- 操作空间控制的前馈项 $\dot J\dot q$（消掉速度相关加速度）。
- 接触约束的加速度级 $J\ddot q+\dot J\dot q=0$。
- `getJointJacobianTimeVariation` 同样支持三参考系抽取。

## 7. 与运动学、CoM、CRBA 的复用关系

`data.J`（世界系运动子空间堆叠）是 Pinocchio 的**公共底料**，被多处复用：

| 算法 | 怎么用 `data.J` |
|---|---|
| [正向运动学](正向运动学解析.md) | 速度递推的另一种视角：$v_i=\sum_{\text{祖先}}J_j\dot q_j$ |
| [质心雅可比](质心与质心动量解析.md) | $J_{\text{com}}$ 逐列 = 质量加权的 $J$ 线/角组合 |
| [CRBA](质量矩阵CRBA解析.md) / [ccrba](质心与质心动量解析.md) | 力集 $Y^cS$ 用的就是 `data.J` 的列（世界系 $S$） |
| [frames](算法总览.md) | frame 雅可比 = 关节雅可比再平移到 frame 位置 |

所以许多算法内部会先 `computeJointJacobians`（或复用已填的 `data.J`），是"算一次、处处用"的典型。

---

## 8. 一句话总结

雅可比 = **一趟 $O(n)$ 前向填 `data.J`，抽取时沿支撑链 + 参考系变换**：

$$
{}^oJ_i={}^oX_iS_i,\qquad v_i=\sum_{j\in\text{support}(i)}{}^oJ_j\dot q_j
$$

- `data.J` 存**世界系运动子空间** ${}^oX_jS_j$，一次算全、供处处复用；
- 某关节雅可比 = 取其**祖先列**（天然稀疏，[稀疏模式见姊妹篇](雅可比稀疏模式解析.md)）；
- 三参考系：**WORLD** 直用、**LOCAL** 用 `actInv` 转回体系、**LOCAL_WORLD_ALIGNED** 只平移作用点（$v^{\text{lin}}\!-\!t\times\omega$）。
