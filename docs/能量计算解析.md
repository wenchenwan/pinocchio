## 1. 三个能量量

| 函数 | 量 | 公式 | 写入 `data` |
|---|---|---|---|
| `computeKineticEnergy(q,v)` | 动能 $T$ | $\tfrac12\dot q^\top M(q)\dot q=\tfrac12\sum_i v_i^\top I_i v_i$ | `kinetic_energy` |
| `computePotentialEnergy(q)` | 势能 $V$ | $-\sum_i m_i\,c_i^\top g$ | `potential_energy` |
| `computeMechanicalEnergy(q,v)` | 机械能 $E$ | $T+V$ | `mechanical_energy` |

都是标量。带 $(q,v)$ 的重载先调 `forwardKinematics` 填 `data.v`、`oMi`，再调不带参数的核心版。

## 2. `computeKineticEnergy`：动能

```cpp
data.kinetic_energy = 0;
for (i=1; i<njoints; ++i) {
  data.kinetic_energy += model.inertias[i].vtiv(data.v[i]);   // ① v_iᵀ I_i v_i
  data.kinetic_energy +=                                       // ② 转子惯量项
    (armature_i.array() * jdata.joint_v().array().square()).sum();
}
data.kinetic_energy *= 0.5;   // 统一乘 ½
```

**核心公式**：

$$
\boxed{\,T=\frac12\sum_{i}v_i^\top I_i v_i+\frac12\sum_i \text{armature}_i\,\dot q_i^2\,}
$$

- **① `vtiv(v)`** = **v**elocity-**t**ranspose-**i**nertia-**v**elocity $=v_i^\top I_iv_i$：单个连杆的动能两倍。空间惯量 $I_i$ 是 6×6，$v_i$ 是该连杆的空间速度（含平动 $\tfrac12mv^2$ + 转动 $\tfrac12\omega^\top\bar I\omega$ + 耦合），`vtiv` 一次算完，见 [空间代数 §5](空间代数运算解析.md)。
- **② 转子惯量**：电机转子经减速比反射的惯量对动能的贡献 $\tfrac12\text{armature}_i\dot q_i^2$，纯关节空间对角项（同 [RNEA §6.2](逆动力学RNEA解析.md)）。
- 最后统一 `*= 0.5`。

> 不支持 mimic 关节（`assert(MimicChecker())`）。

## 3. 为什么不用组装 $M$ 就能算动能

动能的"教科书式"写法是 $T=\tfrac12\dot q^\top M(q)\dot q$，需要先有质量矩阵 $M$（[CRBA](质量矩阵CRBA解析.md)，$O(nd)$）再做二次型。但 energy.hxx **完全不碰 $M$**，只用 $\sum_i v_i^\top I_iv_i$，$O(n)$ 一趟搞定。为什么等价？

**动能对刚体可加**：整机动能 = 各连杆动能之和

$$
T=\sum_i \frac12 v_i^\top I_iv_i
$$

而每个 $v_i$（由 [正向运动学速度递推](正向运动学解析.md) 得到）**已经包含了所有祖先关节的贡献**：$v_i=\sum_{j\in\text{support}(i)}{}^iX_jS_j\dot q_j$。把这个代入 $\sum_i\tfrac12 v_i^\top I_iv_i$ 展开，交叉项 $\dot q_j\dot q_k$ 的系数恰好就是 $M_{jk}$——于是自动等于 $\tfrac12\dot q^\top M\dot q$，**但无需显式写出 $M$**。

$$
\frac12\sum_i v_i^\top I_iv_i \;\equiv\; \frac12\dot q^\top M(q)\dot q
$$

这是"用物理量（每体动能）绕过代数量（矩阵 $M$）"的典型：$M$ 是 $O(n^2)$ 个数，动能只是 1 个标量，直接按体累加比先建 $M$ 便宜得多。

> 反过来，这也给出验证 $M$ 的方法：对每对 $\dot q=e_j+e_k$ 算动能可反推 $M_{jk}$；但要整个 $M$ 还是 CRBA 直接。

## 4. `computePotentialEnergy`：势能

```cpp
data.potential_energy = 0;
const Vector3 g = model.gravity.linear();          // 重力加速度向量，如 (0,0,-9.81)
for (i=1; i<njoints; ++i) {
  com_global = data.oMi[i].translation()
             + data.oMi[i].rotation() * model.inertias[i].lever();   // 连杆世界质心 c_i
  data.potential_energy -= model.inertias[i].mass() * com_global.dot(g);  // −m_i c_i·g
}
```

**核心公式**：

$$
\boxed{\,V=-\sum_i m_i\,c_i^\top g\,}
$$

- **`com_global`** $=c_i^{\text{world}}={}^oM_i\cdot{}^i\!c_i$：连杆质心从局部 `lever()` 变换到世界（旋转 + 平移）。
- **$-m_ic_i\cdot g$**：重力势能。$g$ 是重力**加速度**向量（默认 $(0,0,-9.81)$，指向下）。取点积再取负：若 $g=(0,0,-g_0)$，则 $-m c\cdot g=+m g_0 z$，正是熟悉的 $mgh$（高度越高势能越大）。
- 势能只依赖位形 $q$（通过 `oMi`），不需要速度。

> 等价地 $V=-M\,c^\top g$（$M$=总质量，$c$=整机质心），因为 $\sum m_ic_i=Mc$。但按体累加省了先算整机质心。

## 5. `computeMechanicalEnergy`：机械能与守恒

```cpp
for (i=1; i<njoints; ++i) {
  Pass::run(...);                        // 累加动能（vtiv + armature）
  com_global = ...;                      // 同时累加势能
  data.potential_energy -= mass * com_global.dot(g);
}
data.kinetic_energy *= 0.5;
data.mechanical_energy = data.kinetic_energy + data.potential_energy;  // E = T + V
```

把动能与势能的两趟循环**合并成一趟**（复用同一次遍历），得机械能：

$$
\boxed{\,E=T+V\,}
$$

**用途——验证积分器/无源性**：对**保守系统**（无驱动力、无摩擦、无接触），机械能是**守恒量** $\dot E=0$。所以仿真里追踪 $E$ 是否漂移，是检验数值积分器（如辛积分器 vs 显式欧拉）质量的经典手段——好的积分器 $E$ 长期稳定，差的会单调漂移。也用于验证动力学实现的正确性（自由落体/无外力摆动时 $E$ 应恒定）。

> 有驱动或耗散时，$\dot E=\tau^\top\dot q-P_{\text{friction}}$（功率平衡），可据此检查能量收支。

## 6. 一句话总结

能量 = **一趟 $O(n)$ 按连杆累加的标量**：

$$
T=\frac12\sum_i v_i^\top I_iv_i\ (+\text{armature}),\qquad
V=-\sum_i m_ic_i^\top g,\qquad
E=T+V
$$

- **动能**：按体累加 `vtiv` $=v^\top Iv$，**不必组装 $M$**（因 $v_i$ 已含全部祖先贡献，自动等于 $\tfrac12\dot q^\top M\dot q$）；
- **势能**：连杆世界质心点乘重力 $-m_ic_i\cdot g$，只依赖 $q$；
- **机械能** $E=T+V$ 对保守系守恒，是**验证积分器/动力学实现**的黄金标准。
