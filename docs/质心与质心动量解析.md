## 1. 为什么质心和质心动量重要

- **质心 $c$**：整机质量的等效作用点。双足/人形平衡控制的核心状态（ZMP、capture point 都基于 $c$）。
- **质心动量 $h_g=(k_g,l_g)$**：整个系统**绕质心**的合动量（$l_g$ 线动量、$k_g$ 角动量）。它满足一条极其干净的牛顿-欧拉方程：

$$
\dot h_g = \sum_k f_k^{\text{ext}} \oplus (\text{重力}) \quad\Longleftrightarrow\quad
\begin{cases}\dot l_g = m\ddot c = \sum f_k + mg\\ \dot k_g = \sum (p_k-c)\times f_k\end{cases}
$$

即"外力（含重力）决定质心动量变化率"。这是全身动力学/运动规划（如 centroidal dynamics、动量控制）的基础方程——比全关节动力学低维得多（只有 6 维），却抓住了整机平动+转动的本质。

- **$A_g$（质心动量矩阵 CMM）**：把关节速度映射到质心动量 $h_g=A_g(q)\dot q$。是动量控制、角动量正则化的雅可比。

## 2. 一阶质量矩：所有递推的公共骨架

关键量是**一阶质量矩**（first moment of mass）$\;m_i c_i$（质量 × 质心位置）。整机质心是所有连杆一阶矩之和除以总质量：

$$
\boxed{\,c=\frac{\sum_i m_i c_i}{\sum_i m_i}=\frac{1}{M}\sum_i m_i c_i\,}
$$

四个算法（CoM 位置/速度/加速度、CoM 雅可比、质心动量、CMM）本质上都是**把某种"一阶矩类量"沿运动树自叶向根累加，最后在根处除以总质量或移到质心系**。理解这一条，四个算法就统一了。

代码里 `model.inertias[i]` 提供两个基本量：
- `mass()` = $m_i$（连杆质量）
- `lever()` = ${}^i\!c_i$（连杆质心在**关节 $i$ 局部系**下的位置）

## 3. `centerOfMass`：位置/速度/加速度两趟递推

`centerOfMass(q[,v[,a]])` 先调 `forwardKinematics` 填 `data.v/a`，再按 `KinematicLevel`（POSITION/VELOCITY/ACCELERATION）做两趟递推。

### 3.1 前向趟：算每个连杆的"局部一阶矩"

```cpp
for (i=1; i<njoints; ++i) {
  mass = model.inertias[i].mass();       // m_i
  lever = model.inertias[i].lever();     // 局部质心 c_i
  data.mass[i] = mass;
  data.com[i]  = mass * lever;                                   // ① 一阶矩 m_i c_i
  data.vcom[i] = mass * (v.angular().cross(lever) + v.linear()); // ② m_i ċ_i
  data.acom[i] = mass * (a.angular().cross(lever) + a.linear())
               + v.angular().cross(data.vcom[i]);                // ③ m_i c̈_i（含科氏）
}
```

- **① 位置**：`com[i]` 存的**不是质心位置**，而是**一阶矩** $m_ic_i$（乘了质量）。这样累加时天然是加权和。
- **② 速度**：质心点的速度 = 刚体点速度公式 $v_{\text{lin}}+\omega\times c$，再乘质量得动量式的一阶矩变化率。
- **③ 加速度**：刚体点加速度 $a_{\text{lin}}+\alpha\times c$，**外加** $\omega\times\dot{(mc)}$——这是**科氏项**（点在转动系里，见 [正向运动学 §10 经典加速度](正向运动学解析.md)）。注释明确写 "coriolis part"。

### 3.2 后向趟：一阶矩沿树累加，最后除总质量

```cpp
for (i=njoints-1; i>0; --i) {
  parent = model.parents[i];
  liMi = data.liMi[i];
  data.mass[parent] += data.mass[i];                                          // 累加子树质量
  data.com[parent]  += liMi.rotation()*data.com[i] + data.mass[i]*liMi.translation();  // ★
  data.vcom[parent] += liMi.rotation()*data.vcom[i];
  data.acom[parent] += liMi.rotation()*data.acom[i];
  if (computeSubtreeComs) data.com[i] /= data.mass[i];   // 顺带求各子树质心
}
data.com[0]  /= data.mass[0];   // 除以总质量 → 真正的质心
data.vcom[0] /= data.mass[0];
data.acom[0] /= data.mass[0];
```

**★ 一阶矩的坐标变换**：把子连杆的一阶矩 $m_ic_i$（在子系）搬到父系，是刚体点变换 $R\cdot(m_ic_i)+({}^\lambda t_i)\cdot m_i$：旋转一阶矩，再加"子树质量 × 子原点平移"。这正是**平行轴/一阶矩变换**——`liMi.rotation()*com[i] + mass[i]*liMi.translation()`。

逆序保证处理 $i$ 时子树已并入。最终 `com[0]` 累积了全部一阶矩，**除以总质量** `mass[0]` 得到真正的质心 $c$。速度/加速度同理（它们的一阶矩只需旋转变换，因为平移部分在求导时是常量对齐的）。

> `computeSubtreeComs=true` 时，顺便把每个 `com[i]/=mass[i]` 得到**各子树的质心**（子树平衡分析用）。

## 4. `jacobianCenterOfMass`：质心雅可比

$J_{\text{com}}$ 满足 $\dot c=J_{\text{com}}\dot q$，是质心位置对关节的雅可比（$3\times n_v$）。物理上是**各连杆质心雅可比的质量加权平均**：

$$
\boxed{\,J_{\text{com}}=\frac{1}{M}\sum_i m_i J_{c_i}\,}
$$

后向趟里逐列累加（`JacobianCenterOfMassBackwardStep`）：

```cpp
data.com[parent]  += data.com[i];       // 一阶矩累加（同 §3）
data.mass[parent] += data.mass[i];
Jcols = data.oMi[i].act(jdata.S());     // 世界系运动子空间

for (col : jmodel.nvExtended())
  jointCols(Jcom).col = data.mass[i]*Jcols.col.LINEAR         // 质量 × 线速度分量
                      - data.com[i].cross(Jcols.col.ANGULAR); // − 一阶矩 × 角速度分量
```

- 每列贡献 = $m_i\,(S_{\text{lin}}) - (m_ic_i)\times(S_{\text{ang}})$：运动子空间的线部分乘质量，减去一阶矩叉乘角部分（因为关节转动会让下游质心绕轴划过，产生 $\omega\times c$ 的线速度）。
- 累加完再除以总质量（在外层）得到 $J_{\text{com}}$。
- `computeJacobianCenterOfMass` 复用 `data.J`（整机雅可比列 ${}^oS_i$），所以与 [jacobian](算法总览.md) 共享计算。

## 5. `computeCentroidalMomentum`：质心动量 $h_g$

质心动量 $h_g$ 是整机绕质心的合空间动量。递推同样是"局部动量沿树累加，最后移到质心"：

```cpp
// 前向：每连杆的局部空间动量 h_i = Y_i v_i
for (i=1; i<njoints; ++i) {
  data.mass[i] = Y.mass(); data.com[i] = Y.mass()*Y.lever();  // 一阶矩（为算 com）
  data.h[i] = Y * data.v[i];                                  // ★ 空间动量 = 惯量 · 速度
}
// 后向：动量对偶变换累加到父
for (i=njoints-1; i>0; --i) {
  data.mass[parent] += data.mass[i];
  data.com[parent]  += liMi.rotation()*com[i] + mass[i]*liMi.translation();
  data.h[parent]    += data.liMi[i].act(data.h[i]);   // ★ 动量用 act（力/对偶量变换）
}
data.com[0] /= data.mass[0];                            // 质心

// 把在原点表达的总动量 h[0] 平移到质心系
data.hg = data.h[0];
data.hg.angular() += data.hg.linear().cross(data.com[0]);   // ★ 动量的平移变换
data.vcom[0] = data.hg.linear() / data.mass[0];
```

### 5.1 三个关键点

- **$h_i=Y_iv_i$**（`Y * v`）：连杆空间动量 = 空间惯量作用于空间速度（6D，含线动量与角动量），见 [空间代数 §5](空间代数运算解析.md)。
- **`data.liMi[i].act(h[i])`**：动量是**对偶量（wrench 类）**，沿树上移用 `act`（不是 `actInv`），与 [RNEA 后向力传播](逆动力学RNEA解析.md) 同理。
- **移到质心** `hg.angular += hg.linear × com`：动量从"世界原点"平移到"质心点"时，角动量要加一个 $l\times c$ 的平移耦合项（力/动量的旋量平移公式）。移到质心后 $h_g$ 才有"绕质心"的干净物理意义。

> $l_g=h_g^{\text{lin}}=M\dot c$（总线动量），故 `vcom[0]=hg.linear/mass`。

## 6. `ccrba`：质心动量矩阵 $A_g$（CMM）

`ccrba`（Composite Centroidal Rigid Body Algorithm）算 $A_g$，满足 $h_g=A_g(q)\dot q$（$6\times n_v$）。**它复用 CRBA 的组合刚体惯量** `oYcrb`：

```cpp
forwardKinematics(model, data, q);
for (i=1; i<njoints; ++i)
  data.oYcrb[i] = data.oMi[i].act(model.inertias[i]);   // 世界系本体惯量（种子）

// 后向（CcrbaBackwardStep）
for (i=njoints-1; i>0; --i) {
  J_cols  = data.oMi[i].act(jdata.S());                  // 世界系 S_i → data.J
  Ag_cols = jointCols(data.Ag);
  motionSet::inertiaAction<ADDTO>(data.oYcrb[i], J_cols, Ag_cols);  // ★ Ag列 = Y^c_i · S_i
  data.oYcrb[parent] += data.oYcrb[i];                  // 组合惯量累加（同 CRBA）
}

// 把动量映射移到质心系
data.com[0] = data.oYcrb[0].lever();                    // 从总组合惯量抽质心
for (i=0; i<nv; ++i)
  Ag_ang.col(i) += Ag_lin.col(i).cross(data.com[0]);    // 每列平移到质心
data.hg = data.Ag * v;                                  // 验证：h_g = A_g v
data.Ig = 质心处的组合惯量;                              // Ig：绕质心的总惯量
```

### 6.1 与 CRBA 的同构

对比 [CRBA §6](质量矩阵CRBA解析.md)：CRBA 的 `motionSet::inertiaAction(oYcrb[i], J_cols, Ag_cols)` 算的力集 $F_i=Y_i^cS_i$，**正是 $A_g$ 的列**（未移质心前）。所以：

$$
\boxed{\,A_g\text{ 的第 }i\text{ 关节列块} = Y_i^c\,S_i\quad(\text{移到质心系前})\,}
$$

CRBA 用这个力集去点乘 $S^\top$ 填 $M$；ccrba 直接把它当质心动量矩阵的列，再整体平移到质心。**两者是同一批中间量的两种用法**——这就是为什么 Pinocchio 把力集存进 `data.Ag`（名字就是 centroidal momentum matrix）。

### 6.2 移到质心

组合惯量累加完，`oYcrb[0]` 是"整机焊死"的总惯量，`.lever()` 直接给出质心 $c$。再把每列的角部分加 $A_g^{\text{lin}}\times c$，把动量映射从世界原点搬到质心——同 §5.1 的动量平移。

## 7. $A_g$、$M$、CRBA 的血缘关系

三者共享**组合刚体惯量 $Y^c$** 与**世界系运动子空间 $S$**（`data.J`）：

| 量 | 公式 | 由谁算 |
|---|---|---|
| 力集 $F_i=Y_i^cS_i$ | 组合惯量作用于子空间 | CRBA / ccrba 共用中间量 |
| 质量矩阵 $M_{ij}$ | $S_i^\top F_j=S_i^\top Y^cS_j$ | CRBA |
| 质心动量矩阵 $A_g$ | $[Y_i^cS_i]$ 移到质心 | ccrba |

- 对**浮动基**模型，$M$ 的前 6 行（浮动基那 6 个自由度）与 $A_g$ 直接相关：浮动基关节的 $S$ 是单位阵，故 $M_{\text{base},:}$ 就是（世界原点表达的）动量映射，移到质心即 $A_g$。这解释了"锁住腿只看浮动基 → 得到质心动量"的物理。
- 因此 **CRBA 与 ccrba 复杂度同为 $O(nd)$**，且可在同一次遍历里同时产出（Pinocchio 的 `computeAllTerms` 就利用了这点）。

## 8. 时间导数与 `getComFromCrba`

- **`computeCentroidalMomentumTimeVariation`**：在 §5 基础上多算 $\dot h_g$。前向趟额外算连杆空间力 $f_i=Y_ia_i+v_i\times^*h_i$（正是 [RNEA](逆动力学RNEA解析.md) 的牛顿-欧拉力！），后向 `act` 累加到根，移到质心得 $\dot h_g$。所以 $\dot h_g$ 就是"整机合外力（对偶）"，印证 §1 的动量方程。
- **`dccrba`**：算 $\dot A_g$（$h_g=A_g\dot q\Rightarrow\dot h_g=A_g\ddot q+\dot A_g\dot q$），动量控制里需要。
- **`getComFromCrba`**：若已跑过 CRBA（`oYcrb` 已填），直接 `com[0]=liMi[1].act(oYcrb[1].lever())` 抽质心，$O(1)$，不必重算。

## 9. 一句话总结

质心与质心动量 = **一阶矩/动量沿树累加的两趟 $O(n)$ 递推**：

$$
c=\frac{1}{M}\sum_i m_ic_i,\qquad h_g=\Big(\sum_i {}^gX_i^*\,Y_iv_i\Big),\qquad h_g=A_g\dot q
$$

- **质心**：累加一阶矩 $m_ic_i$（`com[i]` 存的是矩，最后除总质量）；速度/加速度同构，加速度含科氏项。
- **质心动量**：累加连杆动量 $Y_iv_i$（用 `act` 对偶变换），最后**平移到质心**（角部分 $+l\times c$）。
- **$A_g$（CMM）**：列 = $Y_i^cS_i$，**与 CRBA 的力集是同一批量**，移到质心即得；这也是浮动基 $M$ 前 6 行的来源。
