## 0. 拉格朗日动力学方程：所有算法的坐标系

绝大多数算法都是在计算下面这条方程的某一块：

$$
\boxed{\,M(q)\,\ddot q + \underbrace{C(q,\dot q)\dot q + g(q)}_{b(q,\dot q)\ \text{非线性项}} = \tau + \sum_k J_k(q)^\top f_k^{\text{ext}}\,}
$$

| 符号 | 含义 | 谁来算 |
|---|---|---|
| $M(q)$ | 关节空间惯性矩阵（质量矩阵，$n_v\times n_v$，对称正定） | **CRBA** |
| $b(q,\dot q)=C\dot q+g$ | 科氏/离心 + 重力（非线性效应） | **RNEA**（令 $\ddot q=0$）→ `nonLinearEffects` |
| $g(q)$ | 广义重力 | **RNEA**（令 $\ddot q=0,\dot q=0$）→ `computeGeneralizedGravity` |
| $\tau$ | 广义力（关节力矩） | **RNEA** 正问题输出 |
| $\ddot q$ | 广义加速度 | **ABA** / `forwardDynamics` 输出 |
| $J_k$ | 接触/frame 雅可比 | **jacobian / frames** |

- **逆动力学**：给 $(q,\dot q,\ddot q)$ 求 $\tau$ —— RNEA，$O(n)$。
- **正动力学**：给 $(q,\dot q,\tau)$ 求 $\ddot q$ —— ABA，$O(n)$；或 $\ddot q=M^{-1}(\tau-b)$ 用 CRBA+Cholesky，$O(n^2\sim n^3)$。
- 三者关系：$\tau=\text{RNEA}(q,\dot q,\ddot q)$，$b=\text{RNEA}(q,\dot q,0)$，$M=\text{CRBA}(q)$，故 $\ddot q=M^{-1}(\tau-b)$。

## A. 运动学 Kinematics

前向递推 SE(3)/twist，是一切算法的地基。**详解见 [正向运动学解析.md](正向运动学解析.md)**。

| 文件 | 主函数 | 做什么 | 写入 `data` | 复杂度 |
|---|---|---|---|---|
| `kinematics` | `forwardKinematics(q[,v[,a]])` | 位姿 / 空间速度 / 空间加速度递推 | `oMi, liMi, v, a` | $O(n)$ |
| | `updateGlobalPlacements` | 由 `liMi` 刷新全局 `oMi` | `oMi` | $O(n)$ |
| | `getVelocity/Acceleration/ClassicalAcceleration` | 取某关节速度/加速度到指定参考系 | — | $O(1)$ |
| | `getRelativePlacement` | 两关节相对位姿 | — | $O(1)$ WORLD / $O(n)$ LOCAL |
| `frames` | `updateFramePlacements` | 由 `oMi` 算所有 frame 位姿 `oMf` | `oMf` | $O(\text{nframes})$ |
| | `getFrameVelocity/Acceleration` | frame 的速度/加速度 | — | $O(1)$ |
| | `getFrameJacobian` / `computeFrameJacobian` | frame 雅可比 ${}^rJ_f$ | — | $O(n)$ |
| `jacobian` | `computeJointJacobians(q)` | 整机雅可比 $J$（所有关节列，世界系） | `data.J` | $O(n)$ |
| | `getJointJacobian` | 取某关节 6×nv 雅可比（LOCAL/WORLD/ALIGNED） | — | $O(n)$ |
| | `computeJointJacobiansTimeVariation` | $\dot J$（依赖 $q,\dot q$） | `data.J, dJ` | $O(n)$ |

> 雅可比列的稀疏结构（哪些列非零）见 **[雅可比稀疏模式解析.md](雅可比稀疏模式解析.md)**；`data.J` 的定义见 [multibody 子系统解析 §2.5](multibody子系统解析.md)。

## B. 逆动力学 Inverse Dynamics（RNEA 家族）

**详解见 [逆动力学RNEA解析.md](逆动力学RNEA解析.md)**。核心：给定运动求力，两趟递推（前向传播运动、后向传播力）。

| 文件 | 主函数 | 做什么 | 输出 | 复杂度 |
|---|---|---|---|---|
| `rnea` | `rnea(q,v,a[,fext])` | 逆动力学 $\tau=M\ddot q+b$ | `data.tau` | $O(n)$ |
| | `nonLinearEffects(q,v)` | 非线性项 $b(q,\dot q)=C\dot q+g$（$\ddot q=0$） | `data.nle` | $O(n)$ |
| | `computeGeneralizedGravity(q)` | 广义重力 $g(q)$（$\dot q=\ddot q=0$） | `data.g` | $O(n)$ |
| | `computeStaticTorque(q,fext)` | 静态力矩 $g(q)-\sum J^\top f_{\text{ext}}$ | `data.tau` | $O(n)$ |
| | `computeCoriolisMatrix(q,v)` | 科氏矩阵 $C(q,\dot q)$ 显式 | `data.C` | $O(n^2)$ |

## C. 正动力学 Forward Dynamics（ABA 家族）

**详解见 [正动力学ABA解析.md](正动力学ABA解析.md)**。核心：给定力求加速度，三趟递推（铰接体惯量法）。

| 文件 | 主函数 | 做什么 | 输出 | 复杂度 |
|---|---|---|---|---|
| `aba` | `aba(q,v,tau[,fext])` | 正动力学 $\ddot q=M^{-1}(\tau-b)$（铰接体算法） | `data.ddq` | $O(n)$ |
| | `computeMinverse(q)` | 直接算 $M^{-1}$（不显式组装 $M$） | `data.Minv` | $O(n^2)$ |
| `pv` | `pv` / `constrainedABA` | Popov–Vereshchagin：**带约束**的正动力学，一趟解出 $\ddot q$ 和约束力 | `data.ddq, lambda` | $O(n+m)$ |
| `loop-constrained-aba` | `constrainedABA`（闭环） | 闭链约束的正动力学（CLconstrainedABA） | `data.ddq, lambda` | $O(n+m)$ |

## D. 质量矩阵与 Cholesky 分解

**详解见 [质量矩阵CRBA解析.md](质量矩阵CRBA解析.md)** 与 [multibody 子系统解析 §3.5（_fromRow / 稀疏 Cholesky）](multibody子系统解析.md)。

| 文件 | 主函数 | 做什么 | 输出 | 复杂度 |
|---|---|---|---|---|
| `crba` | `crba(q)` | 组合刚体算法，算质量矩阵 $M$（上三角） | `data.M` | $O(nd)$ |
| `cholesky` | `cholesky::decompose(M)` | $M=U D U^\top$，利用分支诱导稀疏 | `data.U, D, Dinv` | $O(nd)$ |
| | `cholesky::solve` / `Uv/Utv/Uiv/Utiv` | 用分解解 $Mx=y$、稀疏乘 $U$/$U^{-1}$ | — | $O(nd)$ |
| | `cholesky::computeMinv` | 由分解求 $M^{-1}$ | `data.Minv` | $O(n^2)$ |
| `constraint-cholesky` | `ContactCholeskyDecomposition` | 约束 KKT 矩阵的稀疏 Cholesky（接触动力学核心） | 自带 | $O((n+m)\cdot)$ |

> $d=$ 树的平均深度。链式结构 $d\approx n$（退化成 $O(n^2)$），分支越多 $d$ 越小。

## F. 约束与接触动力学 Constrained / Contact

带接触/闭环约束的动力学，围绕 KKT 系统与 Delassus 算子（约束空间惯量）。

| 文件 | 主函数 | 做什么 | 复杂度 |
|---|---|---|---|
| `constrained-dynamics` | `constraintDynamics` | 接触前向动力学（KKT，proximal/稀疏 Cholesky） | $O(n+m^3)$级 |
| `contact-dynamics` | `forwardDynamics` / `impulseDynamics` | 经典接触正动力学 / 冲量动力学（老接口，内部 `computeAllTerms`/`crba`） | |
| `impulse-dynamics` | `impulseDynamics` | 碰撞冲量 → 速度跳变 $\Delta\dot q$ | |
| `contact-inverse-dynamics` | `contactInverseDynamics` | 有接触时的逆动力学（求 $\tau$ 与接触力） | |
| `delassus` | `computeDelassusMatrix` / `Inverse` | Delassus 矩阵 $G=J M^{-1}J^\top$（约束空间惯量的逆） | |
| `delassus-operator-*` | `DelassusOperator*`（dense/sparse/rigid-body/cholesky/preconditioned） | Delassus 算子的多种惰性实现（不显式成矩阵，只提供 apply/solve） | |
| `proximal` | `ProximalSettings` | 近端点法（proximal）求解参数（约束求解的正则化/收敛控制） | |
| `preconditioner-base` / `diagonal-preconditioner` | | 迭代求解的预条件子基类 / 对角预条件子 | |

> 约束动力学是 Pinocchio 3 的重点，数学上是 $\begin{bmatrix}M & J^\top\\ J & 0\end{bmatrix}\begin{bmatrix}\ddot q\\ -\lambda\end{bmatrix}=\begin{bmatrix}\tau-b\\ -\dot J\dot q\end{bmatrix}$ 的 KKT 系统。**接触/浮动基背景见 [floating-base-and-contact-dynamics.md](floating-base-and-contact-dynamics.md)**。

## H. 参数辨识回归 Regressor

把动力学写成 **参数线性**形式 $\tau=Y(q,\dot q,\ddot q)\,\pi$，用于辨识每个连杆的惯性参数 $\pi$（质量、质心、惯量 10 维）。

| 文件 | 主函数 | 做什么 |
|---|---|---|
| `regressor` | `computeJointTorqueRegressor` | 关节力矩回归子 $Y$：$\tau=Y\pi$ |
| | `bodyRegressor` / `jointBodyRegressor` / `frameBodyRegressor` | 单刚体的动力学参数回归子 |
| | `computeKineticEnergyRegressor` / `computePotentialEnergyRegressor` | 能量对参数的回归子 |
| | `computeStaticRegressor` | 静力学（质心）回归子 |
| | `computeKinematicRegressor` | 运动学回归子（连杆位姿变化 → 运动学参数） |

## I. 解析导数 Derivatives（可微分动力学）

Pinocchio 的招牌能力：动力学量对 $(q,\dot q,\ddot q,\tau)$ 的**解析（非数值）偏导**，用于最优控制/DDP、梯度优化、SysID。

| 文件 | 主函数 | 求什么导数 |
|---|---|---|
| `kinematics-derivatives` | `computeForwardKinematicsDerivatives` + `getJointVelocityDerivatives` 等 | $\partial(\text{位姿/速度/加速度})/\partial(q,\dot q,\ddot q)$ |
| `rnea-derivatives` | `computeRNEADerivatives` | $\partial\tau/\partial q,\ \partial\tau/\partial\dot q,\ \partial\tau/\partial\ddot q(=M)$ |
| | `computeGeneralizedGravityDerivatives` / `computeStaticTorqueDerivatives` | $\partial g/\partial q$ 等 |
| `aba-derivatives` | `computeABADerivatives` | $\partial\ddot q/\partial q,\ \partial\ddot q/\partial\dot q,\ \partial\ddot q/\partial\tau(=M^{-1})$ |
| `rnea-second-order-derivatives` | `ComputeRNEASecondOrderDerivatives` | RNEA 的二阶偏导（张量，DDP 用） |
| `centroidal-derivatives` | `computeCentroidalDynamicsDerivatives` | 质心动量 $\partial h_g,\partial\dot h_g$ |
| `frames-derivatives` | `getFrameVelocityDerivatives` / `getFrameAccelerationDerivatives` | frame 速度/加速度偏导 |
| `center-of-mass-derivatives` | `getCenterOfMassVelocityDerivatives` | $\partial\dot c/\partial q$ |
| `constrained-dynamics-derivatives` | `computeConstraintDynamicsDerivatives` | 接触动力学的偏导 |
| `impulse-dynamics-derivatives` | `computeImpulseDynamicsDerivatives` | 冲量动力学的偏导 |

> 导数算法都**复用正问题算法的中间量**（如 `data.J, oYcrb, oa_gf`），所以调用前一般要先跑对应的正问题或专门的 `compute...Derivatives`。
