## 1. 四种基本类型：它们各存什么

| 类型 | 头文件 | 内部存储 | 数学对象 |
|------|--------|----------|----------|
| `SE3Tpl` | `spatial/se3-tpl.hxx` | 旋转 `rot`(3×3) + 平移 `trans`(3×1) | 刚体位姿 $M=(R,p)\in SE(3)$ |
| `MotionTpl` | `spatial/motion-tpl.hxx` | 一个 `Vector6 m_data` | 空间速度 Twist $\nu=(v,\omega)$ |
| `ForceTpl` | `spatial/force-tpl.hxx` | 一个 `Vector6 m_data` | 空间力 Wrench $\phi=(f,\tau)$ |
| `InertiaTpl` | `spatial/inertia.hxx` | 质量 `m_mass` + 质心 `m_com` + 转动惯量 `m_inertia`(Symmetric3) | 空间惯量 $\mathbf{I}\in\mathbb{R}^{6\times6}$ |

### 1.1 Motion / Force：一个 6 维向量 + 两个"段视图"

`MotionTpl` 内部**只存一个 `Vector6 m_data`**；`linear()`/`angular()` 不是独立成员，而是这个 6 维向量的
**段引用（segment view）**——所以它们能直接读写、零拷贝：

```cpp
// motion-tpl.hxx：存储
Vector6 m_data;                                            // 唯一的数据成员，6 维
// 访问器：linear/angular 是 m_data 的 3 维子段（可读可写）
ConstLinearType  linear_impl()  const { return m_data.template segment<3>(LINEAR); }   // 索引 0–2
ConstAngularType angular_impl() const { return m_data.template segment<3>(ANGULAR); }  // 索引 3–5
```

> ⚠️ **内存布局：线性在前、角量在后**（`LINEAR`=0–2，`ANGULAR`=3–5；Featherstone 原书相反）。
> 因为整个 twist 是一段连续 `Vector6`，所以 `toVector()` 直接返回 `m_data`、能整体参与 6×6 矩阵乘，
> `linear()`/`angular()` 又能单独取 3 维块——两全其美。`ForceTpl` 结构完全相同（`f`=linear，`τ`=angular）。

### 1.2 SE3：拆成 (R, p) 而非 4×4

```cpp
// se3-tpl.hxx：存储 + 访问器
Matrix3 rot;  Vector3 trans;                 // 只存旋转 3×3 + 平移 3×1
ConstAngularRef rotation_impl()    const { return rot; }
ConstLinearRef  translation_impl() const { return trans; }
```

**为什么不存 4×4 齐次矩阵**：拆成 `(R,p)` 后，所有运算能避开齐次矩阵最后一行 `[0 0 0 1]` 的冗余乘加
（见 [§3](#3-se3位姿的复合求逆作用于点转成矩阵) 每个方法都"直接对 `R,p` 操作"）。需要显式 4×4 时才 `toHomogeneousMatrix()`。

### 1.3 Inertia：存 (m, c, I_c) 而非 6×6

```cpp
// inertia.hxx：存储 + 访问器
Scalar     m_mass;      // 质量 m
Vector3    m_com;       // 质心位置 c（相对该连杆坐标系原点）
Symmetric3 m_inertia;   // 质心处转动惯量 I_c（对称阵，只存 6 个数）
Scalar     mass()    const;  Vector3 & lever();  Symmetric3 & inertia();  // 访问器
```

只存 10 个独立数（1+3+6），需要时用 `matrix()` 展开成完整 6×6 空间惯量（见 [§6](#6-inertia空间动量复合换系与动能)）。
`Symmetric3` 是紧凑对称矩阵类型（存上三角 6 个元），配套 `rotate(R)`（算 $RI_cR^\top$）、`vtiv(ω)`（算 $\omega^\top I_c\omega$）等。

### 1.4 Motion / Force 家族：一套代数、两种存储后端

前面说 `Motion` 存一个 `Vector6`——这只是**其中一种**存储方式。完整的家族是**CRTP 继承链**（`Force` 同构）：

```
MotionBase<Derived>            抽象接口（所有 Motion 的公共 API）
  └─ MotionDense<Derived>      ★ 代数实现层：cross / se3Action / +,-,^ 都在这里【只写一遍】
       ├─ MotionTpl<S,O>       后端①：自己【拥有】一个 Vector6（6 个标量）
       └─ MotionRef<V6>        后端②：只【引用】外部 6D 内存（存一个 Eigen::Ref 胖指针，零拷贝）
```

**关键设计——算法与存储解耦**：所有 Motion 的运算逻辑写在 `MotionDense` 里（用 CRTP 回调派生类取数据，见
[C++语法技巧 §4](C++语法技巧.md)）；`MotionTpl` 和 `MotionRef` 只是**两种"从哪拿数据"的后端**：

| | `MotionTpl`（拥有型） | `MotionRef`（视图型） |
|---|----------------------|----------------------|
| 数据成员 | `Vector6 m_data`（6 标量） | `Eigen::Ref m_ref`（胖指针：地址+步长） |
| 是否拷贝 | 拥有、自管 | **零拷贝**，只引用外部内存 |
| `+`/`-`/`*` | 返回新 `Motion` | 返回新 `MotionPlain`（Ref 不能拥有新结果） |
| `+=`/`-=` | 改自身 | **就地写穿到被引用的外部内存** |
| 生命周期 | 自管 | 不延长源内存寿命，源释放即悬空 |

`MotionRef` 还有个 `MotionRef<const V6>` **只读偏特化**（只给 const 访问器、无 `+=`/`-=`），用于把 `Data` 里的
只读数据安全暴露为 Motion 接口。

**为什么要视图后端**：`Data` 常把几十个关节的速度/加速度/力存成**一整块大缓冲**；`MotionRef` 让你把其中
某一段**当作 Motion 直接读写、零拷贝**——对每步都要遍历几十个关节的 RNEA/ABA 循环是性能关键。

> 记忆：**看到 `MotionDense` 就知道"这是代数实现层"；`MotionTpl`=拥有数据、`MotionRef`=引用数据**。
> 你平时用的 `pinocchio::Motion` 就是 `MotionTpl<double>`。`Force` 家族（`ForceBase/ForceDense/ForceTpl/ForceRef`）结构完全一样。

> **共同设计哲学**：四种类型都**存最少的独立量、把运算写成对分量的直接操作**，只在必要时才展开成大矩阵；
> 且**代数与存储解耦**（`MotionDense` 写算法、`Tpl`/`Ref` 定存储）。这是 Pinocchio 高性能的微观基础——下面每一节的运算都体现这一点。

## 2. skew：反对称矩阵 / 叉乘算子

**文件**：`spatial/skew.hxx`。这个文件提供**6 组**与叉乘相关的工具函数，是把"叉乘变成线性代数"的基础。
逐个展开。

叉乘 $a\times b$ 可写成矩阵乘 $[a]_\times\, b$，其中 $[a]_\times$ 是 $a$ 的**反对称矩阵**（hat 算子）：

$$[a]_\times = \begin{bmatrix} 0 & -a_z & a_y \\ a_z & 0 & -a_x \\ -a_y & a_x & 0 \end{bmatrix}, \qquad [a]_\times b = a\times b$$

### 2.1 `skew(v)` —— 构造 $[v]_\times$

```cpp
M_(0,0)=0;      M_(0,1)=-v[2];  M_(0,2)= v[1];
M_(1,0)= v[2];  M_(1,1)=0;      M_(1,2)=-v[0];
M_(2,0)=-v[1];  M_(2,1)= v[0];  M_(2,2)=0;
```
两个重载：`skew(v, M)`（写进给定 `M`，无返回，省一次拷贝）和 `skew(v)`（返回新 3×3 矩阵，写起来顺手）。
全库几乎所有 "in/out 参数" + "返回值" 双重载都是这个模式。

### 2.2 `addSkew(v, M)` —— 把 $[v]_\times$ **累加**到已有矩阵

```cpp
M_(0,1)-=v[2]; M_(0,2)+=v[1]; M_(1,0)+=v[2];
M_(1,2)-=v[0]; M_(2,0)-=v[1]; M_(2,1)+=v[0];   // 注意：只碰 6 个非对角元，不动对角
```
与 `skew` 的区别：**`+=` 而非 `=`，且不写对角线**（对角恒 0，累加时不必碰）。用于**逐块拼装** 6×6 矩阵时，
往某个 3×3 子块上叠加一个叉乘项，而不覆盖已有内容——解析梯度、`Inertia::variation` 等处常见。

### 2.3 `unSkew(M)` —— 逆运算，从反对称矩阵取回向量

```cpp
v_[0] = 0.5*(M(2,1) - M(1,2));
v_[1] = 0.5*(M(0,2) - M(2,0));
v_[2] = 0.5*(M(1,0) - M(0,1));
```
$[v]_\times$ 的逆：$M x = v\times x \Rightarrow v$。**关键细节**：用 `0.5*(M(i,j)-M(j,i))` 而非直接读某个元素——
即**先取 M 的反对称部分再提取**。这样即使传入的 `M` 不是严格反对称（比如带了数值误差或对称污染），
也能稳健地取出"最接近的"向量。同样有 `(M,v)` 和 `(M)` 两重载。

### 2.4 `alphaSkew(alpha, v)` —— 融合标量的 $[\alpha v]_\times$

```cpp
M_(0,1)=-v[2]*alpha; M_(0,2)= v[1]*alpha; M_(1,2)=-v[0]*alpha;
M_(1,0)=-M_(0,1);    M_(2,0)=-M_(0,2);    M_(2,1)=-M_(1,2);   // 复用已算值 + 反对称性
```
一次算出 $[\alpha v]_\times = \alpha[v]_\times$，把"缩放"和"构造反对称"**融合成一趟**，比先 `skew` 再乘标量少一遍遍历；
还利用反对称性 `M(1,0)=-M(0,1)` 复用已算的元素。用于需要带系数的叉乘项（如 $[\,m\,c\,]_\times$）。

### 2.5 `skewSquare(u, v)` —— 双重叉乘算子 $[u]_\times[v]_\times$

```cpp
C_.noalias() = v * u.transpose();          // C = v·uᵀ
C_.diagonal().array() -= u.dot(v);         //   - (u·v) I
```
满足对任意 $w$：$u\times(v\times w) = C(u,v)\,w$。数学恒等式（BAC-CAB 展开）：

$$[u]_\times[v]_\times = v\,u^\top - (u\cdot v)\,I$$

代码正是这两行——**不真的把两个反对称矩阵乘起来**（那要 27 次乘加），而用"外积 − 标量·单位阵"直接给出，
快得多。用于空间惯量的分块、解析梯度里的二阶叉乘项。

### 2.6 `cross(v, M)` —— 对矩阵**每一列**批量叉乘

```cpp
Mout_.row(0) = v[1]*Min.row(2) - v[2]*Min.row(1);
Mout_.row(1) = v[2]*Min.row(0) - v[0]*Min.row(2);
Mout_.row(2) = v[0]*Min.row(1) - v[1]*Min.row(0);
```
计算 $[v]_\times M$（$M$ 是 3×n），即**把 $v\times(\cdot)$ 同时作用到 $M$ 的每一列**。关键是它**不先构造 $[v]_\times$
再做矩阵乘**，而是直接按行组合——省掉中间的 3×3 矩阵、且对 n 列一次算完。用于 Jacobian、
一批点/向量同时做叉乘变换的场合。

### 小结

| 函数 | 作用 | 相对朴素写法的优化 |
|------|------|--------------------|
| `skew(v)` | 构造 $[v]_\times$ | in/out + 返回值双重载 |
| `addSkew(v,M)` | 把 $[v]_\times$ 累加进 M | `+=` 不覆盖、不碰对角 |
| `unSkew(M)` | 逆：取回 v | 取反对称部分，抗数值污染 |
| `alphaSkew(α,v)` | $[\alpha v]_\times$ | 融合缩放 + 复用反对称元 |
| `skewSquare(u,v)` | $[u]_\times[v]_\times$ | 外积−标量恒等式，避免矩阵相乘 |
| `cross(v,M)` | $[v]_\times M$（列批量） | 不建 $[v]_\times$，按行直算 |

**共同用途**：空间惯量里 $m\,\hat{c}$、所有 twist/wrench 变换里的 $t\times(\cdot)$、解析梯度里的一/二阶叉乘项
——它们是[第 4~7 节](#4-se3-作用于-motion--force伴随与余伴随)那些空间运算的"零件"。

## 3. SE3：位姿的复合、求逆、作用于点、转成矩阵

**文件**：`spatial/se3-tpl.hxx`。`SE3` 存 $(R,p)$（旋转 3×3 + 平移 3×1）。以下所有方法都是
**直接对 `(R,p)` 分量操作**，不走 4×4 齐次矩阵通用乘。约定：`LINEAR`=索引 0–2，`ANGULAR`=索引 3–5。

### 3.1 复合 `M1 * M2`（= `M1.act(M2)`）

把两个刚体变换串联。用 4×4 齐次矩阵推一下就清楚为什么平移项是 $p_1+R_1p_2$：

$$
\begin{bmatrix} R_1 & p_1 \\ 0 & 1\end{bmatrix}
\begin{bmatrix} R_2 & p_2 \\ 0 & 1\end{bmatrix}
=\begin{bmatrix} R_1R_2 & R_1p_2+p_1 \\ 0 & 1\end{bmatrix}
\ \Rightarrow\ M_1M_2 = (\,R_1R_2,\ \ p_1+R_1p_2\,)
$$

```cpp
SE3Tpl act_impl(const SE3Tpl<Scalar, O2> & m2) const
{ return SE3Tpl(rot * m2.rotation(),                       // 新旋转 = R₁R₂
                translation() + rotation() * m2.translation()); } // 新平移 = p₁ + R₁p₂
```

**用途**：FK 递推 `oMi[i] = oMi[parent] * liMi[i]`（[源码解析条目 8/10](源码解析.md)）就是这个。

### 3.2 求逆 `M.inverse()`

由 $M M^{-1}=I$ 解出：旋转取转置（$R\in SO(3)\Rightarrow R^{-1}=R^\top$），平移为 $-R^\top p$：

$$M^{-1} = (R,p)^{-1} = (\,R^\top,\ -R^\top p\,)$$

```cpp
SE3Tpl inverse() const { return SE3Tpl(rot.transpose(),   // R⁻¹ = Rᵀ（无需真求逆）
                                        -rot.transpose() * trans); } // -Rᵀp
```

### 3.3 作用于 3D 点 `act(p)` / `actInv(p)`

把一个点从 b 系坐标变到 a 系（`act`），或反过来（`actInv`）：

$$\underbrace{M\cdot p = Rp + t}_{\texttt{act}}, \qquad \underbrace{M^{-1}\cdot p = R^\top(p - t)}_{\texttt{actInv}}$$

```cpp
Vector3 act_impl   (const Vector3 & p) const { return Vector3(rotation() * p + translation()); }        // Rp+t
Vector3 actInv_impl(const Vector3 & p) const { return Vector3(rotation().transpose() * (p - translation())); } // Rᵀ(p−t)
```

> `actInv` 比"先 `inverse()` 再 `act`"更省——直接用 $R^\top(p-t)$，不额外构造逆变换对象。
> `actInv` 常用于"求相对位姿/误差"，如 IK 里 `data.oMi[JOINT].actInv(oMdes)`（[§4.2](../PINOCCHIO_GUIDE.md)）。

### 3.4 转成矩阵：`toHomogeneousMatrix` / `toActionMatrix` 系列

`SE3` 内部是紧凑的 $(R,p)$，但有时需要展开成显式矩阵（调试、和外部线代库对接、或一次性把变换作用到
一批量上）。共 4 个转换方法：

| 方法 | 产出 | 尺寸 | 作用对象 |
|------|------|------|----------|
| `toHomogeneousMatrix()` | 齐次矩阵 $\begin{bmatrix}R&p\\0&1\end{bmatrix}$ | 4×4 | 3D 点（齐次坐标） |
| `toActionMatrix()` | 伴随矩阵 $\mathrm{Ad}_M$ | 6×6 | Motion（twist） |
| `toActionMatrixInverse()` | $\mathrm{Ad}_{M^{-1}}=\mathrm{Ad}_M^{-1}$ | 6×6 | Motion（逆变换） |
| `toDualActionMatrix()` | 余伴随矩阵 $\mathrm{Ad}_M^{-\top}$ | 6×6 | Force（wrench） |

**`toHomogeneousMatrix`**——就是把 $(R,p)$ 摆进 4×4：

```cpp
M.block<3,3>(LINEAR,LINEAR)  = rot;    // 左上：R
M.block<3,1>(LINEAR,ANGULAR) = trans;  // 右上：p
M.block<1,3>(ANGULAR,LINEAR).setZero();// 左下：0
M(3,3) = 1;                            // 右下：1
```

6×6 的 `toActionMatrix` / `toDualActionMatrix` 是把 [§4](#4-se3-作用于-motion--force伴随与余伴随) 的
Motion/Force 变换写成**显式矩阵**，其分块结构在 §4 详解。

### 3.5 归一化：把旋转投影回 SO(3)

经过大量运算（浮点误差累积、`cast` 换标量、流形积分…）后，`rot` 可能**漂移出 SO(3)**（不再严格正交、
$\det$ 偏离 1）。`normalize()` 把它 snap 回**最接近的合法旋转**（`isNormalized()` 用来检测）：

```cpp
void normalize() { rot = orthogonalProjection(rot); }   // 只修旋转块，trans 无需归一化
```

**`orthogonalProjection`（`math/rotation.hxx`）：用 SVD 求最近旋转矩阵**

```cpp
JacobiSVD svd(mat, ComputeFullU | ComputeFullV);          // mat = U Σ Vᵀ
res.leftCols<2>() = svd.matrixU() * svd.matrixV().transpose().leftCols<2>(); // (U Vᵀ) 的前两列
res.col(2)        = res.col(0).cross(res.col(1));         // 第三列 = 前两列叉乘 → 保证 det=+1
```

- **数学**：与 $A$ 最接近（Frobenius）的正交矩阵是 $UV^\top$（$A=U\Sigma V^\top$，把奇异值全拍平成 1）——
  即**极分解 / 正交 Procrustes** 的解：$\arg\min_{R^\top R=I}\|R-A\|_F = UV^\top$。
- **det=+1 的巧法**：$UV^\top$ 只保证正交（$O(3)$），可能 $\det=-1$（镜像反射，非旋转）。代码只取 $UV^\top$
  **前两列**，**第三列用叉乘 `col0×col1` 重建**——叉乘天然给出右手系，$\det$ 必为 $+1$，一步落进 SO(3)，
  无需"算完再判负翻符号"。
- **为何用 SVD 而非 Gram-Schmidt**：SVD 给**最优**投影，对病态输入更稳健。

> 用途：`randomConfiguration` 后、或用户在积分若干步后手动 `normalize()`，保证 SE3 的旋转部分始终合法。
> 四元数表示的浮动基则用四元数归一化（`explog-quaternion.hxx`）。

## 4. SE3 作用于 Motion / Force：伴随与余伴随

这是空间代数**最核心、也最区别于经典力学**的一步：一个刚体的速度/力**换坐标系**时，光旋转不够——
因为参考点也变了，会额外冒出一个 $t\times(\cdot)$ 的**耦合项**。对 Motion 叫**伴随作用 $\mathrm{Ad}_M$**，
对 Force 叫**余伴随 $\mathrm{Ad}_M^{*}$**。

### 4.0 为什么会有耦合项（先推导，再看代码）

设刚体的空间速度在 b 系为 $(v_b,\omega_b)$（$v_b$ 是"b 系原点处"的线速度）。换到 a 系（$a$ 相对 $b$ 的
位姿为 $M=(R,p)$）后：

- **角速度**只是旋转过去：$\omega_a = R\,\omega_b$（角速度与参考点无关）。
- **线速度**：a 系原点是 b 系原点平移了 $p$（在 a 系度量）的另一点。刚体上不同点的速度差一个
  $\omega\times(\text{位移})$，所以 a 系原点处的线速度 = 旋转过来的 $Rv_b$ 再加上因参考点平移产生的
  $p\times\omega_a$：

$$\boxed{\ \omega_a = R\,\omega_b,\qquad v_a = R\,v_b + p\times\omega_a\ }$$

**那个 $p\times\omega_a$ 就是耦合项**——它是"空间代数"能一步换系的关键，也是经典力学要分别处理平动/转动的麻烦所在。

### 4.1 作用于 Motion（Twist 变换，伴随 $\mathrm{Ad}_M$）

```cpp
// se3Action：把 this(twist，在旧系) 用 m=(R,p) 变换到新系
void se3Action_impl(const SE3Tpl<S2,O2> & m, MotionDense<D2> & v_out) const {
  v_out.angular().noalias() = m.rotation() * angular();                       // ω' = R ω
  v_out.linear().noalias()  = m.rotation() * linear()                        // v' = R v
                            + m.translation().cross(v_out.angular());        //      + p × ω'
}
```

逆作用 `se3ActionInverse`（把新系的量拉回旧系）：

```cpp
v_out.linear()  = m.rotation().transpose() * (linear() - m.translation().cross(angular())); // Rᵀ(v − p×ω)
v_out.angular() = m.rotation().transpose() * angular();                                      // Rᵀ ω
```

**写成矩阵就是 `toActionMatrix`**（linear 在前的 6×6 分块）：

$$
\mathrm{Ad}_M=\begin{bmatrix} R & [p]_\times R \\[2pt] 0 & R \end{bmatrix},\qquad
\begin{bmatrix}v'\\\omega'\end{bmatrix}=\mathrm{Ad}_M\begin{bmatrix}v\\\omega\end{bmatrix}
$$

```cpp
// toActionMatrix：两个对角块 = R，右上块 = [p]×R，左下块 = 0
M.block<3,3>(LINEAR,LINEAR) = M.block<3,3>(ANGULAR,ANGULAR) = rot;   // 对角：R
M.block<3,3>(ANGULAR,LINEAR).setZero();                              // 左下：0
B = M.block<3,3>(LINEAR,ANGULAR);                                    // 右上块 B
B.col(i) = trans.cross(rot.col(i));   // B = [p]×R（逐列做 p × R.col(i)）
```

> 验证一致性：$v' = Rv + [p]_\times R\,\omega = Rv + p\times(R\omega) = Rv + p\times\omega'$，与 4.0 推导、
> 与 `se3Action` 代码完全吻合。

### 4.2 作用于 Force（Wrench 变换，余伴随 $\mathrm{Ad}_M^{*}$）

力是速度的**对偶**，耦合项换到**力矩**行上（力矩受力的力臂影响，而非力受力矩影响）：

$$\boxed{\ f_a = R\,f_b,\qquad \tau_a = R\,\tau_b + p\times f_a\ }$$

```cpp
// se3Action on Force
void se3Action_impl(const SE3Tpl<S2,O2> & m, ForceDense<D2> & f_out) const {
  f_out.linear()  = m.rotation() * linear();                  // f'  = R f
  f_out.angular() = m.rotation() * angular();                 // τ'  = R τ
  f_out.angular() += m.translation().cross(f_out.linear());   // τ' += p × f'   ← 耦合项在力矩行
}
```

**写成矩阵就是 `toDualActionMatrix`**（耦合项落在**左下**块，正好是 4.1 矩阵的"转置搬块"）：

$$
\mathrm{Ad}_M^{*}=\begin{bmatrix} R & 0 \\[2pt] [p]_\times R & R \end{bmatrix},\qquad
\begin{bmatrix}f'\\\tau'\end{bmatrix}=\mathrm{Ad}_M^{*}\begin{bmatrix}f\\\tau\end{bmatrix}
$$

```cpp
// toDualActionMatrix：对角块 = R，右上块 = 0，左下块 = [p]×R
M.block<3,3>(LINEAR,LINEAR) = M.block<3,3>(ANGULAR,ANGULAR) = rot;   // 对角：R
M.block<3,3>(LINEAR,ANGULAR).setZero();                              // 右上：0
B = M.block<3,3>(ANGULAR,LINEAR);   B.col(i) = trans.cross(rot.col(i)); // 左下：[p]×R
```

### 4.3 三个 6×6 矩阵的对照

| 矩阵 | 结构（linear 在前） | 作用 | 数学关系 |
|------|----------------------|------|----------|
| `toActionMatrix` $\mathrm{Ad}_M$ | $\begin{bmatrix}R&[p]_\times R\\0&R\end{bmatrix}$ | Motion 换系 | — |
| `toActionMatrixInverse` | $\mathrm{Ad}_{M^{-1}}$ | Motion 逆换系 | $=\mathrm{Ad}_M^{-1}$ |
| `toDualActionMatrix` $\mathrm{Ad}_M^{*}$ | $\begin{bmatrix}R&0\\ [p]_\times R&R\end{bmatrix}$ | Force 换系 | $=\mathrm{Ad}_M^{-\top}$ |

**一眼看出的对偶关系**：Force 的矩阵就是把 Motion 矩阵的耦合块 $[p]_\times R$ 从**右上搬到左下**——
这正是"运动与力互为对偶"在 6×6 上的体现（对照 [§2.2](../PINOCCHIO_GUIDE.md) 的功率不变性 $\phi^\top\nu$）。

> **性能提示**：日常算法**不显式构造这些 6×6 矩阵**，而是直接调 `act`/`actInv`（走上面的 `se3Action`，
> 只做几次 3×3 乘和叉乘）。`to*Matrix` 只在需要**显式矩阵**（如批量作用、和外部库对接、写解析梯度公式）时才用。

**用途**：RNEA 把子连杆的速度/加速度/力沿运动树在关节坐标系间传递，全靠 `act`/`actInv`（对应
[§4.3](../PINOCCHIO_GUIDE.md) 的 ${}^iX_j$ 空间变换算子）。**换系一步到位，正是空间代数相对经典力学的威力。**

## 5. Motion 的叉乘：v×v 与 v×\*f

空间代数里，twist 之间、twist 对 wrench 之间都有"叉乘"，对应李括号与其对偶。

### 5.0 调用是怎么分派的：`operator^` → `cross` → `motionAction`

用户写的 `v1 ^ v2`（或 `v ^ f`）经过两跳落到实现：

```cpp
// motion-dense.hxx：运算符重载，只是转发到 cross
template<typename M1, typename M2>
typename traits<M1>::MotionPlain operator^(const MotionDense<M1> & v1, const MotionDense<M2> & v2)
{ return v1.derived().cross(v2.derived()); }                     // v1 ^ v2  → v1.cross(v2)

// motion-base.hxx：cross 转发到 cross_impl
cross(const OtherSpatialType & d) const { return derived().cross_impl(d); }

// motion-dense.hxx：cross_impl 反手调 d.motionAction(*this)  —— 真正干活在 motionAction
typename MotionAlgebraAction<D, Derived>::ReturnType cross_impl(const D & d) const
{ return d.motionAction(derived()); }
```

> 关键：`a.cross(b)` 最终执行 `b.motionAction(a)`，即"**用 a 这个 twist 去作用 b**"。`b` 是 Motion 就得
> Motion（5.1），是 Force 就得 Force（5.2）——靠 `motionAction` 的重载在编译期选中。

### 5.1 Motion × Motion（$v_1\times v_2$，李括号）

```cpp
// motion-dense.hxx：v.motionAction(mref) —— 计算 v × (调用者 mref)
void motionAction(const MotionDense<M1> & v, MotionDense<M2> & mout) const {
  mout.linear()  = v.linear().cross(angular()) + v.angular().cross(linear()); // v_线×ω + ω_v×线
  mout.angular() = v.angular().cross(angular());                              // ω_v × ω
}
```

$$v_1\times v_2 = \begin{bmatrix} v_1^{\text{线}}\times\omega_2 + \omega_1\times v_2^{\text{线}} \\ \omega_1\times\omega_2\end{bmatrix}$$

**用途**：RNEA 第一趟里加速度的**科氏/离心偏置项** $\mathbf{v}_i\times\mathbf{s}_i\dot q_i$（[§4.3 / 源码解析条目 8.5](../PINOCCHIO_GUIDE.md)）。

### 5.2 Motion × Force（$v\times^* f$，力的对偶叉乘）

```cpp
// force-dense.hxx：f.motionAction(v) —— 计算 v ×* f
void motionAction(const MotionDense<M1> & v, ForceDense<M2> & fout) const {
  fout.linear()  = v.angular().cross(linear());                              // ω × f
  fout.angular() = v.angular().cross(angular()) + v.linear().cross(linear());// ω × τ + v_线 × f
}
```

$$v\times^* f = \begin{bmatrix} \omega\times f \\ \omega\times\tau + v\times f\end{bmatrix}$$

**用途**：RNEA 第二趟里力的**陀螺项** $\mathbf{v}_i\times^*\mathbf{I}_i\mathbf{v}_i$（[§4.3](../PINOCCHIO_GUIDE.md)）。运算符 `operator^(motion, force)`。

> 记号 $\times^*$（带星）表示**力空间**的叉乘（对偶）。对照 5.1/5.2 的 `motionAction`：Motion 版角量行是
> $\omega\times\omega$，Force 版角量行是 $\omega\times\tau + v\times f$——耦合项位置不同，正是运动/力对偶的体现。
> 库里还有 `alphaCross(α, v)`（融合标量的叉乘）等变体，套路同上。

## 6. Inertia：空间动量、复合、换系与动能

**文件**：`spatial/inertia.hxx`。`InertiaTpl` 存 $(m, c, I_c)$（见 [§1.3](#1-四种基本类型它们各存什么)）。本节梳理它最常用的几个运算。

### 6.1 构造与展开：`InertiaTpl(...)` / `matrix()`

```cpp
InertiaTpl(const Scalar & mass, const Vector3 & com, const Symmetric3 & rotational_inertia); // 由 (m,c,I_c) 构造
static InertiaTpl Zero();  static InertiaTpl Identity();          // 零惯量 / 单位惯量
static InertiaTpl FromEllipsoid(m, a, b, c);  FromBox(...); FromSphere(...); // 由几何体算惯量
Matrix6 matrix() const;    // 展开成完整 6×6 空间惯量矩阵（调试/需要显式矩阵时）
```

完整 6×6 空间惯量（对照 [§2.3](../PINOCCHIO_GUIDE.md)）：

$$\mathbf{I} = \begin{bmatrix} m\,I_3 & -m[c]_\times \\ m[c]_\times & I_c - m[c]_\times[c]_\times \end{bmatrix}$$

日常算法**几乎不调 `matrix()`**——下面的运算都直接对 $(m,c,I_c)$ 分量做，省掉构造 6×6 的开销。

### 6.2 `I * v`：空间动量 $\mathbf{h}=\mathbf{I}\mathbf{v}$

惯量作用在 twist 上得空间动量（一个 wrench）：

$$\mathbf{h} = \mathbf{I}\,\mathbf{v} = \begin{bmatrix} m(v - c\times\omega) \\ I_c\,\omega + c\times(\text{线动量}) \end{bmatrix}$$

```cpp
// __mult__(v, f)：h = I·v，结果写进 f
void __mult__(const MotionDense<MotionDerived> & v, ForceDense<ForceDerived> & f) const {
  f.linear().noalias() = mass() * (v.linear() - lever().cross(v.angular())); // 线动量 = m(v − c×ω)
  Symmetric3::rhsMult(inertia(), v.angular(), f.angular());                  // 角动量 = I_c·ω （Symmetric3 专用乘）
  f.angular() += lever().cross(f.linear());                                  //         += c × 线动量
}
```

`Symmetric3::rhsMult` 是对称矩阵 × 向量的专用实现（只用上三角 6 个元，比通用 3×3 乘少一半乘加）。

**用途**：$\mathbf{f}=\mathbf{I}\mathbf{a}+\mathbf{v}\times^*\mathbf{I}\mathbf{v}$（RNEA 第二趟）里的 $\mathbf{I}\mathbf{a}$、$\mathbf{I}\mathbf{v}$ 都走这里。

### 6.3 `I_a + I_b`：复合刚体惯量（CRBA 核心）

把两个刚体的惯量合成一个等效刚体的惯量——**这是 CRBA（质量矩阵）算法的核心操作**：

$$m_{ab}=m_a+m_b,\quad c_{ab}=\frac{m_ac_a+m_bc_b}{m_{ab}},\quad I_{ab}=I_a+I_b-\frac{m_am_b}{m_{ab}}[c_a-c_b]_\times^2$$

```cpp
// __plus__：Y_{a+b}
const Scalar mab = mass() + Yb.mass();                        // 总质量
const Vector3 AB = (lever() - Yb.lever());                    // 两质心之差 c_a − c_b
return InertiaTpl(
  mab,
  (mass()*lever() + Yb.mass()*Yb.lever()) / mab,              // 加权质心
  inertia() + Yb.inertia()                                    // 转动惯量相加
    - (mass()*Yb.mass()/mab) * Symmetric3::SkewSquare(AB));   // − (m_a m_b/m_ab)[AB]²ₓ（平行轴定理项）
```

- `operator+=`（`__pequ__`）是原地版，CRBA 里沿运动树把子树惯量累加到父节点时用它，避免临时对象。
- `SkewSquare(AB)` 即 $[AB]_\times^2$（用 [§2.5 skewSquare](#2-skew反对称矩阵--叉乘算子) 的恒等式），是平行轴定理的空间代数形式。

**用途**：CRBA 复合刚体惯量 $\mathbf{I}_{\text{subtree}}^c$（[§4.5](../PINOCCHIO_GUIDE.md)）。

### 6.4 `I.se3Action(M)`：把惯量变换到另一坐标系

FK/CRBA 需要把连杆惯量从其局部系表达到父/世界系：

```cpp
InertiaTpl se3Action_impl(const SE3Tpl<S2,O2> & M) const {
  return InertiaTpl(mass(),                                   // 质量不变
                    M.translation() + M.rotation() * lever(), // 新质心 = p + R·c
                    inertia().rotate(M.rotation()));          // 新转动惯量 = R·I_c·Rᵀ
}
```

`inertia().rotate(R)` 算 $R I_c R^\top$（`Symmetric3` 保持对称性的专用旋转）。**用途**：`appendBodyToJoint`
把连杆惯量装到关节、CRBA 沿树把惯量搬到父系。

### 6.5 `vtiv(v)`：动能（的 2 倍）

$$\mathbf{v}^\top\mathbf{I}\mathbf{v} = 2\times\text{动能}$$

```cpp
Scalar vtiv_impl(const MotionDense<MotionDerived> & v) const {
  const Vector3 cxw(lever().cross(v.angular()));             // c × ω
  Scalar res = mass() * (v.linear().squaredNorm() - 2*v.linear().dot(cxw));
  res += mass() * cxw.squaredNorm();                        // （下方合并写法等价）
  res += inertia().vtiv(v.angular());                       // ωᵀ I_c ω
  return res;
}
```

不构造 $\mathbf{I}$ 也不做 $\mathbf{v}^\top(\mathbf{I}\mathbf{v})$ 两步，直接给出标量。**用途**：`computeKineticEnergy`（[§4.5.1](../PINOCCHIO_GUIDE.md) 从动能出发推 CRBA）。

### 6.6 相关变体

`vxi(v)`（$\mathbf{v}\times^*\mathbf{I}$，6×6）、`ivx(v)`（$\mathbf{I}\times\mathbf{v}$）、`variation(v)` 等，用于解析梯度里惯量项对速度的导数——套路同上，均"直接对 $(m,c,I_c)$ 分量算、不构造 6×6"。

### 6.7 与 6×6 矩阵的双向转换（互逆的一对）

紧凑 $(m,c,I_c)$ 与完整 6×6 空间惯量之间有**一对互逆**的转换：

**正向 `matrix()` / `operator Matrix6()`：$(m,c,I_c) \to$ 6×6**（展开，见 [§6.1](#6-inertia空间动量复合换系与动能)）

$$\mathbf{I} = \begin{bmatrix} m\,I_3 & (m[c]_\times)^\top \\ m[c]_\times & I_c - m[c]_\times[c]_\times \end{bmatrix}$$

`operator Matrix6() const { return matrix(); }` 还提供**隐式转换**，让 `Inertia` 能当 6×6 矩阵用（见 [C++语法技巧 §17](C++语法技巧.md)）。

**逆向 `explicit InertiaTpl(const Matrix6 & I6)`：6×6 $\to (m,c,I_c)$**（反解）

```cpp
mass()   = I6(LINEAR, LINEAR);                       // ① m = 左上块对角元（左上=m·I₃）
mc_cross = I6.block<3,3>(ANGULAR, LINEAR);           //   左下块 = m[c]×
lever()  = unSkew(mc_cross);  lever() /= mass();     // ② unSkew(m[c]×)=m·c，÷m → c
Matrix3 I3(mc_cross*mc_cross); I3 /= mass();         // ③ m²[c]ₓ[c]ₓ ÷m = m[c]ₓ[c]ₓ
I3 += I6.block<3,3>(ANGULAR, ANGULAR);               // ④ + (I_c − m[c]ₓ[c]ₓ) = I_c（撤销平行轴项）
inertia() = Symmetric3(I3);                          //   存 I_c
```

- ① $m$ 取左上块对角元；② 左下块 `unSkew` 得 $m c$ 再 ÷$m$ 得 $c$；
- ③④ 右下块**加回** $m[c]_\times[c]_\times$（撤销平行轴移位）恢复质心惯量 $I_c$：$m[c]_\times[c]_\times + (I_c - m[c]_\times[c]_\times) = I_c$。
- **`explicit`**：禁止隐式转换（非任意 6×6 都是合法惯量）；**`assert(...isZero(I6-I6ᵀ))`**：断言对称，`check_expression_if_real` 对 AD 标量跳过检查。

> 一句话：`matrix()` 展开、`InertiaTpl(Matrix6)` 反解，构成"紧凑 ↔ 6×6"的**双向闭环**——日常算法走紧凑分量，需显式矩阵或从外部矩阵构造时才用这对转换。

**本节小结**：`Inertia` 把"质量分布"压成 10 个数，所有运算（动量 `*`、复合 `+`、换系 `se3Action`、动能 `vtiv`、
6×6 双向转换）都直接对 $(m,c,I_c)$ 操作——它们分别撑起 RNEA、CRBA、FK、能量计算。

## 7. exp / log：李群与李代数的桥

**文件**：`spatial/explog.hxx`（SO(3)/SE(3)）、`spatial/log.hxx`（log3/log6 的实现体）、
`spatial/explog-quaternion.hxx`（四元数版）。这是[流形积分/差分](../PINOCCHIO_GUIDE.md)（§2.1）的底层。

### 7.1 为什么需要 exp/log —— 弯空间没法直接加减

旋转不住在平坦的向量空间里，而住在**弯曲的流形/李群 $SO(3)$** 上。你**不能**把一个"旋转向量"直接加到
一个"旋转矩阵"上——加完就不再是合法旋转了。正确做法是在**切空间（李代数 $\mathfrak{se}(3)$）**里做加减，
再用 exp/log 在"弯的群"和"平的切空间"之间来回：

$$\underbrace{\mathfrak{se}(3)}_{\text{平：可加减的 6D 向量}} \xrightarrow[\ \exp\ ]{\ \ } \underbrace{SE(3)}_{\text{弯：位姿}} \xrightarrow[\ \log\ ]{\ \ } \mathfrak{se}(3)$$

- **`exp`**：切向量（twist）→ 群元素（位姿）。物理含义：以恒定 twist 运动**单位时间**后到达的位姿。
- **`log`**：群元素 → 切向量。物理含义：单位时间内能产生该位姿的那个 twist。
- 这正是 [§2.1](../PINOCCHIO_GUIDE.md) 里 `integrate`（$q\oplus v = q\cdot\exp(v)$）与 `difference`
  （$q_1\ominus q_2 = \log(q_2^{-1}q_1)$）的底层。

### 7.2 SO(3)：`exp3` / `log3`（Rodrigues 公式）

**`exp3(ω)`**：旋转向量 $\omega$（轴 × 角）→ 旋转矩阵 $R$。用 Rodrigues 公式（$\theta=\|\omega\|$）：

$$\exp_3(\omega) = I + \frac{\sin\theta}{\theta}[\omega]_\times + \frac{1-\cos\theta}{\theta^2}[\omega]_\times^2$$

```cpp
const Scalar t = math::sqrt(v.squaredNorm() + eps*eps);   // θ = ‖ω‖（+eps² 防 0）
SINCOS(t, &st, &ct);
const Scalar alpha_vxvx = (1 - ct)/t2;                     // (1-cosθ)/θ²  → [ω]²ₓ 的系数
const Scalar alpha_vx   = st/t;                            // sinθ/θ       → [ω]ₓ  的系数
Matrix3 res(alpha_vxvx * v * v.transpose());               // 外积项（= [ω]²ₓ + θ²... 的等价展开）
res.coeffRef(0,1) -= alpha_vx * v[2];  ...                 // 叉乘项 [ω]ₓ（6 个非对角元）
ct = ...; res.diagonal().array() += ct;                    // 对角项
```

> 代码不真的构造 $[\omega]_\times$ 再做矩阵乘方，而是用 $vv^\top$（外积）+ 手填叉乘项 + 对角项，直接给出 $R$。

**`log3(R)`**（实现在 `spatial/log.hxx` 的 `log3_impl`）：$R$ → $(\theta, \text{轴})$ → 旋转向量。逆运算：

```cpp
// 主干：由 cosθ=(tr R−1)/2 得 θ，再 ω = θ/sinθ · (R 的反对称部分)
theta = ...;  res = (theta/sin(theta)) * unSkew(R - Rᵀ)/... ;
// 奇异分支：θ≈π 时 sinθ→0，改从 R 的对角线 compute_theta_axis 取轴（见 log.hxx:100）
```

**关键难点**：$\theta\approx\pi$ 时 $\sin\theta\to0$，"从反对称部分取轴"失效；代码专门走
`compute_theta_axis`，从 $R$ 的对角元恢复轴。这是 `log3` 比 `exp3` 复杂得多的原因。

### 7.3 SE(3)：`exp6` / `log6`

**`exp6(ν)`**，$\nu=(v,\omega)$：旋转部分照走 Rodrigues；**平移部分**要乘一个依赖 $\omega$ 的
"左雅可比" $V(\omega)$（因为边转边移，平移被旋转耦合）：

$$\exp_6(v,\omega) = \Big(\ \underbrace{\exp_3(\omega)}_{\text{旋转}},\ \ \underbrace{V(\omega)\,v}_{\text{平移}}\ \Big),\qquad V(\omega)=I+\frac{1-\cos\theta}{\theta^2}[\omega]_\times+\frac{\theta-\sin\theta}{\theta^3}[\omega]_\times^2$$

代码把 $V(\omega)v$ 展开成三项（避免构造 $V$ 矩阵）：

```cpp
// 平移： trans = α_v·v + α_w·(ω·v)ω + α_wxv·(ω×v)
trans.noalias() = alpha_v * v + (alpha_w * w.dot(v)) * w + alpha_wxv * w.cross(v);
// 旋转： 同 exp3 的手填方式
rot.noalias() = alpha_wxv * w * w.transpose();
rot.coeffRef(0,1) -= alpha_v * w[2];  ...
rot.diagonal().array() += diagonal_term;
```
其中 `alpha_v=sinθ/θ`、`alpha_wxv=(1−cosθ)/θ²`、`alpha_w=(1−sinθ/θ)/θ²`。

**`log6(M)`**（`log6_impl`）：$M=(R,p)$ → twist $\nu=(v,\omega)$。$\omega$ 走 `log3(R)`，
$v = V(\omega)^{-1}p$。有三个重载入口：从 `SE3`、从 `(四元数, 平移)`、从 4×4 齐次矩阵。

**用途**：IK 的 6D 误差 `log6(iMd)`（[§4.2](../PINOCCHIO_GUIDE.md)）、流形 `integrate`/`difference`、SE(3) 插值。

### 7.4 系数的泰勒兜底：数值奇异 + autodiff 的共同根源

`exp3/exp6/log*` 里所有系数都是 $\dfrac{\text{三角函数}}{\theta^k}$ 形式，$\theta\to0$ 时是 $0/0$。代码统一用
`internal::if_then_else` 在小角度切到**泰勒展开**：

```cpp
alpha_v = if_then_else(LT, t, precision, 1 - t2/6,        // θ 很小：sinθ/θ ≈ 1 − θ²/6
                                          st/t);          // 否则：正常算
```

- **数值稳健**：避免小角度除以近零的 $\theta$ 而爆炸。
- **与 autodiff 的关系**：普通 `if` 在 [autodiff](源码解析.md#3-autodiff) 下会丢分支导数；`if_then_else` 对 AD 标量
  会把**两条分支都录进磁带**，所以 exp/log 这些含分支的数学也能被自动微分。这就是为什么全库分支都写成
  `if_then_else` 而非 `if`（见[源码解析条目 3](源码解析.md)）。

### 7.5 Jexp / Jlog / Hlog：这些映射的雅可比与 Hessian

exp/log 是非线性映射，做优化/梯度时需要它们对参数的导数：

| 函数 | 含义 | 主要用途 |
|------|------|----------|
| `Jexp3(ω)` / `Jexp6(ν)` | $\exp$ 的（右）雅可比 | 把切空间扰动传到群上；`integrate` 的导数 |
| `Jlog3(R)` / `Jlog6(M)` | $\log$ 的（右）雅可比（3×3 / 6×6） | **IK 链式法则**：把 SE(3) 误差正确反传到关节空间 |
| `Hlog3(R,...)` | `log3` 的 Hessian（二阶导） | 二阶优化 / 二阶解析导数 |

**`Jlog6` 最常用**：IK 里误差是 `log6(iMd)`，要对 $q$ 求导必须乘 `Jlog6(iMd)`——这正是
[§4.2.2](../PINOCCHIO_GUIDE.md) 反复强调的"为什么需要 Jlog6"。示例见
[inverse-kinematics.py/.cpp](../examples/inverse-kinematics.py) 里的 `pinocchio.Jlog6(...)`。

### 7.6 四元数版本（浮动基必需）

**文件**：`spatial/explog-quaternion.hxx`。浮动基的旋转以**单位四元数**存（7 维 $q$ 的后 4 维），
所以需要针对四元数的 `exp3`/`log3`/`Jexp`：

- `quaternion::exp3(ω)` → 单位四元数；`quaternion::log3(quat)` → 旋转向量；
- `log6(quat, trans)` 直接从"四元数+平移"求 twist（避免先转成旋转矩阵）。

**用途**：`integrate(model, q, v)` 对浮动基那 6 维（3 转 + 3 移）走的就是四元数版 exp——这是[§2.1](../PINOCCHIO_GUIDE.md)
"人形与固定基最本质差异"的落地实现。

### 小结

> `exp/log` 是"平切空间 ↔ 弯李群"的桥：`exp3/6` 用 Rodrigues/左雅可比把 twist 变成位姿，`log3/6` 求逆；
> 所有系数用 `if_then_else` 做**小角度泰勒兜底**（既防数值奇异，又让 autodiff 可导）；`Jexp/Jlog/Hlog`
> 提供其导数（`Jlog6` 是 IK 的关键）；四元数版专供浮动基。**这一层撑起了 `integrate`/`difference`/IK/插值。**

## 一句话定位

> `spatial/` 是 Pinocchio 的**数学词汇表**：把刚体的位姿、速度、力、惯量都表示成紧凑的 `(R,p)` / `(线,角)`
> 结构，并提供复合、求逆、坐标变换（伴随/余伴随）、叉乘、惯量作用、exp/log 这几类**直接对分量操作、
> 不走通用矩阵乘**的高效运算。上层所有算法（FK/RNEA/ABA/CRBA/质心/IK）都是这些空间运算的组合——
> 读懂本文档，第 4 章的算法实现就只剩"把这些积木按公式拼起来"。
